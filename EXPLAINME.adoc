= Hybrid Automation Router -- EXPLAINME

== Intelligent event routing for automation targets

[quote, README.adoc]
____
The Hybrid Automation Router (HAR) is an intelligent routing layer that
receives automation events from multiple sources (filesystem watchers,
webhooks, queues, schedules) and routes them to the best automation target
based on capabilities, tags, priorities, and configurable strategies.
____

HAR is a Rust workspace of 7 crates (core, config, dispatch, health, metrics,
router, CLI) backed by Idris2 ABI definitions and an Ephapax linear-types
guarantee for exactly-once delivery.
See the README.adoc architecture diagram for the full event flow.

**Caveat:** Phase 1 -- the routing engine compiles and tests pass, but
production deployment with live RPA Elysium targets is not yet validated.
