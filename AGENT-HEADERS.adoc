== Required file headers (read before creating any source file)

A pre-commit hook rejects any staged source file that is missing the
required licence + owner header. This is *strict, literal-substring
matching* — a close-but-not-exact header fails the commit with
`+ERROR: File $file is missing correct Owner: ...+`. This document is
the authoritative reference so you don’t get bitten (see issue #51).

=== What the hook checks

On every staged file with one of these extensions —
`+.zig .ex .idr .eph .py .js .ts .rs .c .h .adoc .md+` — it requires
*both*:

[arabic]
. An SPDX licence line:
* `+SPDX-License-Identifier: MPL-2.0+` for *code*, or
* `+SPDX-License-Identifier: CC-BY-SA-4.0+` for *docs* (`+.md+`,
`+.adoc+`).
. The *exact owner literal*, character-for-character:
+
....
Jonathan D.A. Jewell <j.d.a.jewell@open.ac.uk>
....

=== ⚠ The gotcha that bites agents

The estate’s SPDX copyright line uses a *parenthesised handle*:

....
SPDX-FileCopyrightText: 2026 Jonathan D.A. Jewell (hyperpolymath) <j.d.a.jewell@open.ac.uk>
....

That `+(hyperpolymath)+` *breaks the literal substring* the hook wants,
so the copyright line alone does *not* satisfy the hook. The fix is to
add a *separate `+Owner:+` line* carrying the exact literal (no
parenthetical):

....
// Owner: Jonathan D.A. Jewell <j.d.a.jewell@open.ac.uk>
....

Other rejected variants seen in practice: wrong email
(`+<jonathan@hyperpolymath.org>+`), or a copyright line that omits the
email.

=== Canonical header templates

*Rust / Zig / C / H (`+//+` or `+/* */+` comments):*

[source,rust]
----
// SPDX-License-Identifier: MPL-2.0
// SPDX-FileCopyrightText: 2026 Jonathan D.A. Jewell (hyperpolymath) <j.d.a.jewell@open.ac.uk>
// Owner: Jonathan D.A. Jewell <j.d.a.jewell@open.ac.uk>
----

*Idris2 / Ephapax (`+--+` comments):*

[source,idris]
----
-- SPDX-License-Identifier: MPL-2.0
-- SPDX-FileCopyrightText: 2026 Jonathan D.A. Jewell (hyperpolymath) <j.d.a.jewell@open.ac.uk>
-- Owner: Jonathan D.A. Jewell <j.d.a.jewell@open.ac.uk>
----

*AsciiDoc / Markdown (`+//+` for adoc, `+<!-- -->+` for md):*

[source,adoc]
----
// SPDX-License-Identifier: CC-BY-SA-4.0
// SPDX-FileCopyrightText: 2026 Jonathan D.A. Jewell (hyperpolymath) <j.d.a.jewell@open.ac.uk>
// Owner: Jonathan D.A. Jewell <j.d.a.jewell@open.ac.uk>
----

=== The consistent local hook

`+just install-hooks+` installs a version-controlled pre-commit hook
that runs `+fmt-check+` + `+lint+` *and* a _lenient_ header check —
lenient meaning it accepts the estate’s `+(hyperpolymath)+` copyright
form directly, so files that follow the estate standard pass without
needing the extra `+Owner:+` line. If your clone still has the older
strict estate-seeded hook, re-run `+just install-hooks+` to replace it.
