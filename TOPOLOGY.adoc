=== Current Implementation Status (verified source inventory, 2026-11-23)

[cols="2,3,3",options="header"]
|===
|Area |Present on `main` |Not yet demonstrated

|Rust workspace
|Ten crates including `har-meta`, `har-install` and `har-abi`
|Production deployment with one real ingestion-to-effect path

|Router / dispatcher
|Seven strategies, adapter trait, bounded retry, circuit breaker,
per-target semaphore, in-memory and JSONL DLQ, optional NATS publisher
|End-to-end consumer-effect assurance and crash-safe idempotency

|Declarative interlingua
|Resource graph, provenance, ownership-transfer model, A2ML v0.1 codec
|Complete graph -> plan -> apply -> observe -> lift and external federation

|Install domain
|Tier-1 schema and hermetic simulated-executor file-effect tests
|Real sandboxed/traced installer execution and tiers 2-5

|Formal and FFI
|Idris2 source and historical proof register; Zig scaffold
|Current compiler evidence and correspondence to deployed Rust runtime

|Backend and UI
|Metrics collector and health library
|Gleam service, PanLL HAR panels and operational telemetry export

|Governance / CI
|Workflow definitions, RSR documentation and machine-readable legacy files
|Passing current CI, verified DEED/K9 conformance, production release gates
|===

There is **no reliable overall percentage** across these heterogeneous
milestones. The former dashboard contained superseded phase numbers and
claimed absent monitoring panels were complete. It has been retired
rather than promoting those figures as current evidence.

=== Update Protocol

When updating this topology, distinguish observed implementation,
demonstrated tests and intended future components. Update the diagram
when the architecture changes; update status only against a specific
revision and evidence. Do not manufacture aggregate completion
percentages, and do not mark scaffold components production-ready
without an end-to-end acceptance test.
